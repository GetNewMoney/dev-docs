# Support

Email `tech@getnew.money` for:

- DEV access
- destination registration
- API key rotation
- payment or mint verification
- integration questions

Include:

- your company name
- `orderId`
- request timestamp
- HTTP status
- sanitized error response

Never include your API key, bank credentials, OAuth credentials, or a full customer transaction payload.

Use [GitHub issues](https://github.com/GetNewMoney/dev-docs/issues) for documentation corrections that do not contain sensitive information.
